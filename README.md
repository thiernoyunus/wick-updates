# wick-updates

Sparkle appcast feed + release archives for the Wick macOS app.

`appcast.xml` here is what running copies of Wick poll (see `SUFeedURL` in
Wick's Info.plist). Don't hand-edit it — it's generated by
`Wick/script/release.sh`, which builds, signs, notarizes, and publishes a new
version, then updates this file and pushes it.
